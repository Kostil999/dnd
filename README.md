# 🐉 ДнД Мастер

Мобильное веб-приложение (PWA) для игры в **Dungeons & Dragons 5e** вчетвером с **ИИ-мастером подземелий**, который рассказывает историю голосом.

## Возможности
- **📖 Мастер без ИИ (бесплатно, офлайн)**: 6 готовых приключений, включая большую историю «Колыбельная для чудовища» (4 сюжетные линии, 6 концовок), а также («Тайна Пепельной шахты», «Проклятие Туманной топи», «Серебряный караван», «Крепость Чёрного Клыка», «Башня безумного мага») и генератор случайных подземелий. На каждом шаге — не меньше 4 вариантов действий, у каждого героя своя личная история, группа может разделяться. Мастер зачитывает историю голосом, вы выбираете действия, приложение бросает проверки по навыкам героев и ведёт пошаговый бой с инициативой, атаками, заклинаниями, лечением, зельями и спасбросками от смерти. API-ключ не нужен.
- **ИИ-мастер (Claude)** ведёт игру по правилам D&D 5e, озвучивает рассказ голосом, просит броски и сам меняет хиты, опыт, золото и предметы героев.
- **Голосовой ввод**: нажмите 🎤 и скажите, что делает ваш герой (Chrome на Android, Safari на iPhone).
- **Генератор персонажей**: 13 рас, 12 классов, 13 предысторий, стандартный набор / 4к6 / покупка очков, навыки, спасброски, КД, хиты, атаки, заклинания, умения по уровням 1–20, снаряжение, личность. Можно создать случайного героя и всё отредактировать.
- **Кубики**: к4, к6, к8, к10, к12, к20, к100, формулы (`2к6+3`, `4к6kh3`), преимущество и помеха.
- **Правила**: справочник D&D 5e с поиском (бой, действия, состояния, заклинания, отдых, расы, классы и т. д.).
- Работает офлайн (кроме ИИ-мастера), данные хранятся на телефоне.

## Как открыть на телефоне
1. В репозитории на GitHub: **Settings → Pages → Source: GitHub Actions**.
2. Влейте эту ветку в `main` — workflow `.github/workflows/pages.yml` опубликует сайт.
3. Откройте `https://<ваш-логин>.github.io/dnd/` на телефоне.
4. Добавьте на главный экран: Android — меню ⋮ → «Установить приложение»; iPhone — «Поделиться» → «На экран Домой».
5. Для ИИ-мастера во вкладке **Настройки** вставьте API-ключ Anthropic (console.anthropic.com → API Keys). Для режима «Мастер без ИИ» ключ не нужен.

> Ключ хранится только в браузере телефона и отправляется напрямую в API Anthropic. Не делитесь им и не вставляйте его в чужие копии приложения.

## Как играть
1. **Герои** → создайте до 4 персонажей (или «Быстрый старт» во вкладке «Игра»).
2. **Игра** → «Начать приключение».
3. Выберите, кто говорит (имя героя внизу), скажите или напишите действие.
4. Когда мастер просит бросок, появится кнопка 🎲 — нажмите, результат уйдёт мастеру автоматически.

## Техника
Чистый HTML/CSS/JS без сборки. ИИ — официальный `@anthropic-ai/sdk` (собран в `js/vendor/anthropic-sdk.js`), модель по умолчанию Claude Opus 5.5 с серверным резервом на случай отказа. Озвучка — Web Speech API.
